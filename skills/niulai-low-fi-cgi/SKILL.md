# NiuLai · 低精度 CGI

把角色与场景编译成原创的千禧年前后低预算 3D 动画截图：粗糙、近似、迟钝、严肃，并因不熟练建模、简陋贴图与低端渲染自然产生怪诞感。

## 工作流程

1. 完整读取 `references/style.json`。
2. 把 StyleSpec 视为可独立迁移的视觉合同；本 Skill 不依赖任何内置参考图。
3. 获取或合理推断 `environment_variables` 中的变量值。十个 Cookbook 基础变量与四个 NiuLai 扩展变量都必须被填入。
4. 用变量替换 `prompt_template` 中全部 `{{UPPER_SNAKE_CASE}}` 占位符；存在未替换项时停止生成并补全变量。
5. 应用全部 `style_fidelity_anchors`、构图、字幕、颜色、画面处理、虚拟摄影和 `rule_system` 约束。
6. 将完成后的正向提示词直接交给生图模型，不传入内置图片路径、图片 URL、base64 图片或 reference/init/control-image 字段。只有用户在当前请求中主动提供图片时，才把它作为本次内容或构图输入。
7. 生图模型支持 negative prompt 时，附加 `rule_system.avoid` 与 `rule_system.negative_prompt`。若用户主动提供待转换图片并明确要求保留其中的虚构角色、文字、标识或道具，则删除与这些保留项冲突的负向词；负向提示不能覆盖内容锁定。
8. 检查首轮结果是否像现代毛毡玩具、黏土手办、PBR 材质或整帧柔焦；若是，先只做一次“贴图化”修正：移除真实绒毛、立体颗粒、复杂 bump、法线与粗糙度变化，把毛发、布纹、树皮、草叶、金属磨损和阴影都烘焙成贴在模型表面的低清 diffuse 图像。把 texel 尺度放大约 3–5 倍；近处使用 nearest 或弱 bilinear 采样，保留可辨认的 texel 色块，只有远处 mip 层变脏变糊；保留 UV 拉伸、接缝、镜像、平铺和不一致 texel 密度。若模型已退化成体素或极端折面，则适度增加轮廓分段；若模型过于精细丝滑，则简化二级形体、关节和轮廓转折，但不要用夸张减面代替粗糙贴图。
9. 检查首轮是否仍像一比一角色模型或现代打光。若是，做一次“误差化与去光泽”修正：只锁定 3–5 个身份锚点，让每个主体出现 3–5 个不均匀的比例、五官、肢体、关节、服装或左右对称误差；同时移除动态高光、AO、反弹光、真实反射与材质分层，把实时明暗压成 2–4 块粗顶点色阶，并使用低清、接触不准或略漂浮的阴影。误差必须像不熟练资产制作，不得靠鱼眼、画面拉伸、融化或极端减面伪造。

## 迁移边界

- 迁移粗糙早期实时建模、受控形体误差、低清 diffuse 贴图映射、错误 texel 密度、UV 缺陷、钝化顶点光照、朴素构图与 VCD 介质感。
- 原创生成时新建主体、动作、道具、地点、对白和关系，不复刻既有作品中的角色身份、人物面孔、原对白或镜头排列。
- 用户主动提供待转换图片时，把它只作为当前任务的内容与构图输入：保留身份、人数、动作含义、空间关系、关键道具与文字，但不要把原图当作精确 model sheet 或一比一建模标准。除非用户明确要求精确比例，否则用主色块、标志性头部元素和关键服饰维持识别，同时允许可见的形体误差；不要把该图加入可迁移的风格参考包。
- 保持一本正经、天真且不自知的叙事语气。不要把画面做成主动堆梗、故意 glitch 或精致的互联网 meme。
- 原创生成时，不主动复刻真实人物、公共人物、品牌、现有 IP、平台 UI、水印或来源角标。
- 用户主动提供待转换图片并明确要求保留其中的虚构角色时，必须保留该角色身份、可见服装特征、动作与构图，不得匿名化、替换或重新设计；该例外只适用于当前编辑目标，不得把角色加入可复用风格参考包。

## 输出检查

- 第一眼像低预算早期 3D 动画帧，而不是现代低多边形插画或精致手办渲染。
- 角色与环境采用 fixed-function 时代中等偏低面数的实时网格：轮廓保留足够分段，二级形体少、关节和部件连接生硬、绑定僵硬；不使用现代 subdivision-surface 丝滑平滑，也不能退化成夸张体素、方块肢体或大片三角切面。
- 可识别不等于一比一。每个主体应有 3–5 个彼此独立且不均匀的建模偏差：头身或躯干比例约 8%–20%、左右肢体粗细或长度约 5%–15%、手脚及耳鼻喙等末端部件约 10%–25%、五官位置约为头宽的 3%–8%，以及关节错位、衣服轻微悬空或穿插。误差不能对所有角色套用同一种模板，也不能破坏身份锚点与动作含义。
- 表面本身基本平坦。毛发、布料、树皮、草地和磨损必须像“画在模型上的旧贴图”，而不是实际长出的绒毛或立体颗粒；近处能看见低 texel 密度和放大约 3–5 倍的色块，远处 mip 层才变脏变糊，并保留 UV 拉伸、接缝、平铺、镜像和纹理尺度错乱。不能用整帧模糊代替低清贴图。
- 山川树木由少量基础模型重复搭建，草地与树冠能看出平铺贴图。
- 光线只负责让物体可见，不负责真实塑造体积：最多一盏弱主光加恒定环境亮度，主体只有 2–4 块宽泛顶点明暗，动态高光近乎为零；禁止 AO、反弹光、HDRI、真实反射和材质专属光泽。阴影只能是低清硬边 shadow map 或简单 blob shadow，允许接触不准、漏光或轻微漂浮。
- 如使用字幕，必须是原创文案，并呈现白字深色粗描边的低清 VCD 硬字幕效果。
